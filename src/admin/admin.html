Administrator sign-in
Reviewing the shared blocklist requires an admin account.
There is no sign-up here, and no password is stored in the extension: an admin account lives on the ClearView server and is created there (npm run create-admin in the backend repository). This form only signs it in, and the server re-checks the account on every action. If every password is refused, the deployment has none to offer — a stored hash alone can never be checked — so set SUPER_ADMIN_PASSWORD on the server, or rotate the account with npm run create-admin -- --reset.
